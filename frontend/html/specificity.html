CSS SPECIFICITY

Specificity determines which CSS rule wins when multiple rules target the same element.

1. ELEMENT VS CLASS

The class selector wins over the element selector.

2. CLASS VS ID

The ID selector wins over the class selector.

3. TWO CLASSES

Both selectors have the same level. The rule that comes later wins.

4. MORE SPECIFIC SELECTOR

.card .text is more specific than .text

5. INLINE STYLE

Inline style wins over normal CSS rules.

6. !IMPORTANT

!important overrides normal CSS rules.

7. FINAL SPECIFICITY CHALLENGE

Which CSS rule will win?

my ans: #main.text wins
